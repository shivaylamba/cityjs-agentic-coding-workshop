# Lab 01: Give your agent project instructions

15 minutes

AGENTS.md is a Markdown file that tells a coding agent how to work in this project. We will write one, then check that the agent reads it.

## What to do

### 1. Create your own project

Keep this separate from the downloaded workshop materials.

```text
mkdir cityjs-session-planner
cd cityjs-session-planner
git init -b main
mkdir docs
mkdir src
```

### 2. Write the instructions

Copy the working-agreement template into AGENTS.md. Add one keyboard-accessibility rule. For Claude, create CLAUDE.md containing @AGENTS.md. Templates are linked below.

### 3. Check a fresh chat

Open Codex or Claude in this folder. Ask it to locate the instruction files and explain the rules. Do not let it build the app yet. Save your observation in docs/learning-log.md.

```text
git add .
git commit -m "Define workshop working agreement"
```

## Files you need

- [AGENTS.md template](https://cityjs-agentic-coding-attendees.shivaylamba.chatgpt.site/downloads/AGENTS.md.txt)
- [CLAUDE.md template](https://cityjs-agentic-coding-attendees.shivaylamba.chatgpt.site/downloads/CLAUDE.md.txt)

## You are done when

- A fresh agent chat finds your project instructions.
- You can explain the rule your pair added.

## Try one change

Change one rule, start another fresh chat and check what it loads.

## Prompt help

```text
Read the applicable project instructions and list their paths. Summarise the app purpose, explicit non-goals, verification commands and actions that need a separate release decision. Do not create application code. Identify three questions a vague request to "build a conference planner" leaves unanswered. Return facts separately from assumptions.
```

## Stuck?

If instruction discovery fails, explicitly attach/open AGENTS.md in the client and label that run as manually supplied context. Check your launch directory and nested overrides. Do not edit your global instruction files during this workshop.
