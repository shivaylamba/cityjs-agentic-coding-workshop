# Lab 02: Decide what the app must do

20 minutes

A spec says what the app must do. Acceptance criteria are examples you can check. A plan splits that work into small tasks.

## What to do

### 1. Write your spec

Use the example spec for docs/spec.md. Keep its required behaviour. Choose your own conflict message and empty-agenda display. Consecutive sessions are allowed; overlapping ones are rejected.

### 2. Ask for a plan only

Ask your agent to write docs/plan.md. The first task is catalog, add/remove, clash prevention and local persistence. Filters, favorites and export come later.

### 3. Review and save

Check the plan matches your decisions. One person will own App.tsx; filters and favorites will have separate files. Commit the approved documents.

```text
git add docs
git commit -m "Approve planner acceptance criteria and task graph"
```

## Files you need

- [Example spec](https://cityjs-agentic-coding-attendees.shivaylamba.chatgpt.site/downloads/spec.md)
- [Session fixture](https://github.com/shivaylamba/cityjs-agentic-coding-workshop/blob/main/materials/reference/src/sessions.ts)

## You are done when

- Your spec includes one allowed and one rejected time example.
- Your plan approves only the core planner for the next lab.

## Try one change

Ask whether “allow any two sessions” conflicts with “reject overlapping sessions.” Resolve the answer yourselves.

## Prompt help

```text
Read AGENTS.md and docs/spec.md. Do not edit code. First list ambiguities and decide which require my product decision. Then propose a dependency-ordered implementation plan with acceptance IDs, expected files, validation and risks per task. Keep filters and favorites independent behind typed props; reserve App.tsx and shared types for one integrator. We have a three-hour workshop. Propose the smallest first working slice and stop for review.
```

## Stuck?

Use the supplied spec as a recovery aid, then change one acceptance example yourself and ask the agent to adapt the plan. Guided completion still requires explaining the decision and showing the corresponding check.
