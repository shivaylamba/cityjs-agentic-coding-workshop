# Lab 03: Build the first working planner

25 minutes

Build one complete journey: click Add, check the scheduling rule, update the agenda and show the result. The agent writes code; you check it.

## What to do

### 1. Ask your agent to build the core app

Use React, TypeScript and Vite, your spec and the supplied fixture. Include add/remove, duplicate/full/clash rejection and safe local persistence. Leave filters, favorites and export for later.

### 2. Run it and try the journey

Run the checks below, then open the URL Vite prints. Add Opening the agent loop; reject Concurrent choices; add Spec clinic; refresh; remove a session. Check each result.

```text
npm run typecheck
npm test
npm run build
npm run test:e2e
npm run dev -- --host 127.0.0.1
```

### 3. Save the working app

Inspect the diff and check results. Commit only the intended files, then name the checkpoint.

```text
git diff --check
git add .
git commit -m "Build and verify the core planner"
git tag checkpoint-03
```

## You are done when

- Clashes are rejected; consecutive sessions are allowed.
- Refresh keeps the agenda, and the real checks pass.

## Try one change

Move a session end time forward by one minute. Predict the clash result, then check it.

Do not implement filters, favorites or export yet. Run checks, inspect the browser journey, and report actual evidence. Do not deploy or push.

## Stuck?

The packet includes a complete reference React app. Use it in a separate recovery folder, run npm ci and npm run check, and continue the experiment. It contains later features: explicitly record this as recovery rather than claiming you built them already. Do not overwrite uncommitted work.
