# Lab 05: Build two features in separate worktrees

25 minutes

A worktree is a separate checkout of your Git repository. Give one agent filters and another favorites, then combine their work.

## What to do

### 1. Prepare two checkouts

Save and commit current work first. From the original project, create the worktrees.

```text
git status --short
git tag parallel-base
git worktree add -b feat/filters ../cityjs-filters parallel-base
git worktree add -b feat/favorites ../cityjs-favorites parallel-base
```

### 2. Assign the work

In cityjs-filters, build title/room filtering. In cityjs-favorites, build the favorites control/helper. Use the agreed props. Workers must not edit App.tsx, shared types or package files. Review and commit each worker’s changes.

### 3. Merge and connect the features

Return to the original project. Merge each branch, then have one integrator wire the components and persistence. Test search, room and favorites-only together.

```text
git merge --no-ff feat/filters
git merge --no-ff feat/favorites
# Wire App.tsx, then run:
npm run check
npm run test:e2e
git add .
git commit -m "Integrate filters and favorites"
git tag checkpoint-05
```

## Files you need

## You are done when

- Each worker used its assigned checkout and files.
- Combined filters work, and the earlier agenda checks still pass.

## Try one change

If a worker wants to change a shared prop, ask it to propose the change to the integrator first.

## Prompt help

```text
You are worker A on feat/filters. Confirm your working directory and branch. Read the frozen interface in docs/plan.md. Implement title search plus room filtering with AND semantics. Own only src/features/Filters.tsx, src/filter.ts and its test. Do not edit App.tsx, shared types, domain rules, package files or the lockfile. Do not create subagents. Run relevant checks. Return changed files, acceptance evidence, assumptions, and the exact parent wiring the integrator must perform. Stop before merging or pushing.

Worker B adaptation: own only src/features/Favorites.tsx, src/favorites.ts and its test; implement favorite toggling and a favorites-only control using the frozen props. Follow the same boundaries and return format.
```

## Stuck?

Do not force a second agent if the laptop struggles. Run A then B in their worktrees, or have one pair member handle each branch on separate laptops. If a worker edited shared files, ask it to return a patch proposal for the integrator rather than blindly merging.
