# Lab 06: Try bounded autonomy

15 minutes

Bounded autonomy means letting the agent complete a task inside clear limits. Everyone builds export; the instructor assigns a guided or autonomous approach.

## What to do

### 1. Start from the same checkpoint

Use the integrated planner. Create an export branch and record the starting commit.

```text
git switch -c experiment/export
git rev-parse HEAD
```

### 2. Build agenda export

Download cityjs-agenda.txt with time, exact title and room, ordered by start time then ID. An empty agenda shows a message without downloading. No new dependencies, push or deploy. Follow your assigned supervision approach.

### 3. Inspect and score

Open the downloaded file. Try an empty agenda and a title with punctuation. Use the scorecard, record interventions and time, then commit the reviewed feature.

## Files you need

- [Comparison scorecard](https://cityjs-agentic-coding-attendees.shivaylamba.chatgpt.site/downloads/experiment-scorecard.md)

## You are done when

- The downloaded text matches the selected agenda.
- You recorded results and interventions, including anything unfinished.

## Try one change

Use a title with quotation marks and a non-ASCII character. Does it survive unchanged?

## Prompt help

```text
Implement the agenda text export acceptance criteria from this lab on the current branch. Read AGENTS.md and docs/spec.md first. You may edit only the export helper, its tests and the smallest App wiring needed. No dependencies, pushes, merges, deployments or spec changes. Sort by start minute then ID; preserve exact titles; include time and room; show a clear message without downloading for an empty agenda; release download resources. Work independently, run the real relevant checks, and inspect the result. Stop at a contradiction, blocked environment or the host time limit. Report changed files, commands/exits, acceptance evidence and remaining risks. Do not claim unrun browser checks passed.
```

## Stuck?

If your agent times out, stop it, inspect its current diff and score only the completed evidence. The reference export function is in the recovery app. Do not spend the next review block waiting for a model response.
