# Lab 08: Deploy and test the hosted app

15 minutes

A local pass does not prove the hosted app works. Publish a preview, test its actual URL and record the result.

## What to do

### 1. Check the candidate

Commit the intended app first. Run the checks and record the SHA.

```text
git status --short
npm run check
npm run test:e2e
git rev-parse HEAD
```

### 2. Create a preview

From your app folder, run vercel. Check the account and project; use Vite with dist output. The planner needs no model API key.

```text
vercel
```

### 3. Test the actual hosted URL

Try add, clash rejection, consecutive sessions, refresh, combined filters, favorites and export. Check keyboard use and a narrow screen. Record the URL, SHA and results. Choose production only after these pass.

- The important journey works on the actual preview URL.
- Your report identifies the commit, URL and remaining limits—or says LOCAL ONLY.

## Stuck?

If hosting login or networking fails, use npm run preview and record LOCAL ONLY. Follow the instructor’s hosted demo without claiming your own deployment passed. The remaining five minutes are for questions, not emergency account provisioning.
